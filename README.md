# tuitris
A lightweight, terminal-based classic tetris game. The simplest way to play tetris.

## Installation
Just download the binary from the releases!
(Note: Currently, only Linux support is available)

After downloading, you can run it from a terminal by referring to its path. However, we suggest you to create a **symlink** on your bin. Just run the following command in your terminal.

```bash
sudo ln -s /path/to/tuitris/binary /usr/local/bin/tetris
```

Once that's done, you just need to run `tetris` on your terminal to play!
Currently, tuitris can't save your **high score**, but it will print the level reached, the amount of rows cleared and the score obtained after the game's over.
